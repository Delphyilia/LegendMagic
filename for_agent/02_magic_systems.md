# 3大国家魔法体系 詳細仕様書

## 1. ローランド帝国 魔法体系（Roland）
- **思想・特徴**:
  - 純粋な攻撃力と殲滅速度を追求した超攻撃特化・遠距離砲台体系。
  - 通常魔法は詠唱と魔法陣展開が必要だが、**国家の中でローランドにのみ「上位魔法」が存在する**。
  - 上位魔法は魔法陣・詠唱を一切必要とせず、一言で即時発動する破格の破壊力を持つ（エンドコンテンツ「運命の破壊者」撃破で解禁）。

### 魔法リスト
1. **求めるは雷鳴>>>稲光<いづち> (Izuchi)**:
   - **分類**: 通常魔法
   - **体系**: ローランド帝国
   - **詠唱文**: `求めるは雷鳴>>>稲光<いづち>`
   - **消費マナ**: 25 / **詠唱時間**: 40 ticks (2.0秒)
   - **挙動**: 詠唱中、周囲に放電エフェクトが発生。詠唱完了時、視線先（射程30m）の敵に直撃する直線・必中雷撃スナイプ。青い火花と雷光を放つ。
   - **役割**: 単体瞬間DPS最強。複写眼装備時はダメージ2倍。
2. **稲死光 (Inajikou)**:
   - **分類**: 上位魔法（要：「運命の破壊者」撃破解禁）
   - **体系**: ローランド帝国
   - **詠唱文**: `稲死光`（無詠唱）
   - **消費マナ**: 50 / **詠唱時間**: 0 ticks (即時発動)
   - **挙動**: 魔法陣展開および詠唱待機ゼロ。トリガーした瞬間に目標地点または視線方向を焼き払う極大の雷撃。
   - **役割**: 決戦兵器。
3. **求めるは震牙>>>倒地<ちがしら> (Chigashira)**:
   - **分類**: 通常魔法（ボス「運命の破壊者」も使用）
   - **体系**: ローランド帝国
   - **詠唱文**: `求めるは震牙>>>倒地<ちがしら>`
   - **消費マナ**: 35 / **詠唱時間**: 50 ticks (2.5秒)
   - **挙動**: 地盤を揺らし、目標地点の地面から巨大な岩石の杭（Earth Spike）が次々と噴出して敵を串刺しにし、空高くノックアップ（打ち上げ）する。
   - **重要設定**: ブロック破壊は行わず安全。地面の下で物理的に発動する地脈攻撃であるため、「殲滅眼（イーノ・ドゥーエ）」でも防ぐことができない。

## 2. ルーナ帝国 魔法体系（Runa）
- **思想・特徴**:
  - アイテムやポーションの消費なしで、バニラサバイバルを快適にする生活支援・ユーティリティ体系。
  - 低消費マナで手軽に取り回しができる。

### 魔法リスト
1. **救いの風を (SukuinoKazewo)**:
   - **体系**: ルーナ帝国
   - **詠唱文**: `救いの風を`
   - **消費マナ**: 10 / **詠唱時間**: 20 ticks (1.0秒)
   - **挙動**: 術者の足元から常時上昇気流を発生させ、低速落下（Slow Falling, 60秒）を付与。
   - **利点**: ファントムの被膜・低速落下のポーションの代用。高所移動や落下死防止。
2. **救いの炎を (SukuinoHonoowo)**:
   - **体系**: ルーナ帝国
   - **詠唱文**: `救いの炎を`
   - **消費マナ**: 10 / **詠唱時間**: 15 ticks (0.75秒)
   - **挙動**: 視線方向へファイヤーチャージを発射、または狙ったブロックに着火。
   - **利点**: 火打ち石と打ち金・ファイヤーチャージの代用。暗所での緊急着火やネザーポータル起動。
3. **救いの雷を (SukuinoIkazuchiwo)**:
   - **体系**: ルーナ帝国
   - **詠唱文**: `救いの雷を`
   - **消費マナ**: 20 / **詠唱時間**: 30 ticks (1.5秒)
   - **挙動**: 狙った地点に天然の落雷を召喚。
   - **利点**: 帯電クリーパーの生成、村人の魔女化、避雷針の代用など。

## 3. エスタブール王国 魔法体系（Estabul）
- **思想・特徴**:
  - 精霊や魔獣との契約を交わし、自己への宿し（身体強化）や空間制圧、使役を行う体系。
  - ローランドの「直接直線ビーム」と被らないよう、**「自己強化」「上空誘導ホーミング」「空間重力吸引」**に差別化。

### 魔法リスト
1. **我・契約文を捧げ・大地に眠る悪意の精獣を宿す (Spirit Beast / 自己強化)**:
   - **体系**: エスタブール王国
   - **詠唱文**: `我・契約文を捧げ・大地に眠る悪意の精獣を宿す`
   - **消費マナ**: 40 / **詠唱時間**: 40 ticks (2.0秒)
   - **挙動**: 己の肉体に悪意の精獣を宿し、120秒間、移動速度上昇 II・攻撃力上昇 II・耐性 IIを付与。
   - **役割**: 近接格闘・インファイター特化。
2. **我・契約文を捧げ・大気に眠る光の精獣を宿す (Light Spirit Beast / 信号弾・索敵)**:
   - **体系**: エスタブール王国
   - **詠唱文**: `我・契約文を捧げ・大気に眠る光の精獣を宿す`
   - **消費マナ**: 25 / **詠唱時間**: 25 ticks (1.25秒)
   - **挙動**: 上空高く光の精獣（信号弾）を放ち、周囲広範囲を強烈に照らし出す。同時に、半径64ブロック以内のすべての敵Mobに発光（Glowing, 30秒）を付与（ウォールハック索敵）。
   - **役割**: 暗所・洞窟・夜間の索敵およびマルチプレイでの目印。
3. **我・契約文を捧げ・天空を踊る光の魔獣を放つ (Sky Dancing Beast / 誘導ホーミング爆撃)**:
   - **体系**: エスタブール王国
   - **詠唱文**: `我・契約文を捧げ・天空を踊る光の魔獣を放つ`
   - **消費マナ**: 30 / **詠唱時間**: 35 ticks (1.75秒)
   - **挙動**: 直線に飛ぶIzuchiとは異なり、天空へと一度駆け上がった光の魔獣が、遮蔽物の裏に隠れた敵や空中の敵を自動追尾して急降下爆撃する。
   - **役割**: 遮蔽物無視・対空・誘導攻撃。
4. **我・契約文を捧げ・宙を覆う精霊の力を放つ (Vortex of Spirits / エスタブール最強魔法・青い渦)**:
   - **体系**: エスタブール王国
   - **詠唱文**: `我・契約文を捧げ・宙を覆う精霊の力を放つ`
   - **消費マナ**: 60 / **詠唱時間**: 60 ticks (3.0秒)
   - **挙動**: 目標空間に約8秒間持続する巨大な「青い渦」を生成。周囲12ブロック以内のすべての敵・矢・投擲物を中心へ猛烈に引き寄せて拘束し、継続的な斬撃ダメージを与え続ける（持続AoEブラックホール）。
   - **役割**: 空間制圧・敵集敵。拘束した敵の群れにローランドのIzuchiや倒地、稲死光を叩き込む強力なコンボが可能。
