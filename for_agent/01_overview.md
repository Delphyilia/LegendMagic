# LegendMagic 全体設計仕様書：概要と差別化方針

## 1. プロジェクト概要
『LegendMagic』は、ライトノベル・アニメ作品『伝説の勇者の伝説』（伝勇伝）の世界観および魔法体系をMinecraft上に再現する本格魔法・遺物Modである。

---

## 2. 他の主要魔法Modとの差別化（Iron's Spells / Ars Nouveau）

| 要素 | Iron's Spells 'n Spellbooks | Ars Nouveau | **LegendMagic（本作）** |
| :--- | :--- | :--- | :--- |
| **コンセプト** | アクションRPG風スペルスロット | グリフ合成・魔術自動化サンドボックス | **国家別魔法体系 × 魔眼（解析/暴走/吸収） × 忘却欠片（遺物）** |
| **魔法の性質** | 汎用RPG属性（火・氷・雷・神聖等） | 形態＋効果＋修飾の自由組み合わせ | **国家ごとの明確な思想・詠唱文・幾何学魔法陣** |
| **詠唱・操作** | ホットバー/ホイール即時・短チャージ | パルチメント使用 | **ラジアルメニュー選択 ＋ 魔法陣展開＆詠唱チャージ（ローランド上位のみ無詠唱即発動）** |
| **リソース** | マナバー ＋ 属性パワー装備 | マナバー ＋ Source自動化 | **王道マナシステム ＋ 魔眼によるリスク/リターン管理** |
| **遺物・装備** | 魔導士ローブセット・スペルブック | 魔導防具・アクセサリ | **忘却欠片（専用クラフト台・鍛冶台で強化する独立した武器・秘宝）** |
| **エンドコンテンツ**| ボス討伐・上位スクロール集め | ワイルドハント・ポータル | **内面のナイフによる異次元研究所探索 ＆ 超強敵「父」への挑戦** |

## 3. 主要コアシステム一覧
1. **3大国家魔法体系**:
   - **ローランド (Roland)**: 遠距離・直接破壊・高DPS砲台。父討伐後に無詠唱上位魔法が解禁。
   - **ルーナ (Runa)**: サバイバル便利・生活支援・バニラ代替。
   - **エスタブール (Estabul)**: 精霊/魔獣との契約・自己身体強化・空間制圧。
2. **操作・発動インターフェース**:
   - ラジアルメニュー（円環UI）による直感的な術選択。
   - 通常魔法は詠唱時間＋幾何学魔法陣展開（チャージ）。被弾による中断リスク。
   - ローランド上位魔法のみ、詠唱・魔法陣なしで即時発動。
3. **魔眼システム (Eye System)**:
   - **複写眼（アルファ・スティグマ）**: 他者の魔法を目視解析して即時習得＋威力強化。使いすぎや瀕死で敵味方・地形ごと崩壊させる「暴走」リスク。
   - **殲滅眼（イーノ・ドゥーエ）**: 自らの魔法が使用不可になる代わりに、大気中の魔力・他者の魔法を喰らって無効化＆自己強化（対父ボス戦の鍵。地中隆起の「倒地」など物理現象は喰らえない）。
4. **忘却欠片（魔法遺物 / Relics）**:
   - 魔法システムとは独立したホットバー携行の秘宝。
   - 通常攻撃（左クリック）＋固有スキル（右クリック、CT制）。
   - 各国構造物チェストの「遺物の欠片」から専用クラフト台で作成。専用鍛冶台でCT短縮や能力強化。
   - Cataclysm風スポナーによる遺物ボスの再挑戦・周回。
5. **エンドコンテンツ「父」と新ディメンション**:
   - アイテム「内面のナイフ」で研究所ディメンションへ転移。
   - 最奥のボス「父」は他Mod（Cataclysm, L2 Hostility等）で強化されたプレイヤーをも圧倒する無詠唱魔法乱射の天才。
   - 撃破報酬により「ローランド上位魔法」が解禁。
