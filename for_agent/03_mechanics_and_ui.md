# 操作・システム・魔眼（Eye System） 仕様書

## 1. 魔法発動とインターフェース
### 1.1 ラジアルメニュー（Radial Menu）
- 専用キー（デフォルト: `R`キー）長押しで画面中央に円環（ラジアル）メニューが表示。
- **10スロット固定**: 魔導書（Grimoire）にセットされた最大10の魔法が円環状に等分配置される。
- **体系別カラーコード**:
  - ローランド魔法（Roland）: 赤・紅蓮枠（攻撃系）
  - エスタブール魔法（Estabul）: 青・蒼藍枠（契約・使役・空間系）
  - ルーナ魔法（Runa）: 白・薄緑枠（生活・便利系）
- マウスカーソルを向けた方向のスロットがハイライトされ、キーを離すことで選択・アクティブセットされる。

### 1.2 詠唱（Casting）と魔法陣展開
- **通常魔法**:
  - 発動キー（または右クリック）で詠唱開始。
  - **移動制限**: 詠唱中は移動速度が50%低下（詠唱スタンス）。
  - **魔法陣展開**: 術者の足元に、体系色（ローランド:赤、エスタブール:青、ルーナ:白緑）の幾何学魔法陣が回転・展開。
  - **HUD表示**: 詠唱ゲージおよび呪文名・詠唱文が表示される。
  - **詠唱中断（Interrupt）**: 詠唱中に被ダメージを受けると詠唱が強制キャンセルされる（ただし、ノックバック耐性値や耐性ポーション効果により中断確率を軽減・防止可能）。
  - 詠唱完了の瞬間に魔法が発動。
- **上位魔法（ローランド専用・要解禁）**:
  - 詠唱時間：0 tick（完全無詠唱）。
  - 魔法陣展開なし、移動制限なし、被弾中断なし。
  - トリガー即時に最大威力が発動。

### 1.3 マナシステム（Mana System）と成長・HUD仕様
- **HUD配置**: 画面右下（ホットバー右脇）に青いマナバーを表示。
- **初期ステータス（Config調整可能）**:
  - デフォルト最大マナ: **10,000**（`defaultMaxMana`）
  - 最大マナ上限（Cap）: **50,000**（`maxManaCap`）
  - 毎秒自然回復量: **50 マナ/秒**（`manaRegenPerSecond`）
- **マナ成長システム（熟練度育成）**:
  - 魔法を唱えてマナを消費するたび、**消費マナの1%（`manaGrowthRate`）が最大マナに恒久還元・加算**され、上限（50,000）まで自動成長する。
- **殲滅眼装備時のHUD切り替え**:
  - 殲滅眼（イーノ・ドゥーエ）着用時は青いマナバーが非表示となり、**漆黒＆深紅の「魔力蓄積バー」**（`殲滅蓄積: ○○ (覚醒: ○○秒)`）に動的切り替えされる。
- **制限**: マナ不足時は詠唱不可となり、警告メッセージまたは効果音で通知。

### 1.4 魔導書（Grimoire）の入手・仕様
- **役割**: 複写眼でコピーした魔法を自動記録し、10のスロットにセットするための解析記録書。手に持って右クリックで管理GUI（詳細プレビュー・ページ送り機能付き）が開く。
- **入手方法（両対応）**:
  1. **初回スポーン時自動配布**: ワールドに初めて参加・スポーンした際、インベントリに1冊自動でプレゼントされる。
  2. **通常クラフト（紛失時対応）**: 「本（book）1個」＋「クモの目（spider_eye）1個」の不定形クラフトでいつでも再作成可能。

## 2. 魔眼システム（The Eyes）
魔眼は通常の魔法とは異なり、Curiosの専用スロット（`magic_eye`）に装備することで効果を発揮する特殊な眼球アイテム。

### 2.0 入手・クラフトレシピ
- **複写眼（アルファ・スティグマ）**:
  - 中央に「クモの目（spider_eye）」、四隅（X字・クロス配置）に「エンダーアイ（ender_eye）」を配置してクラフト。
- **殲滅眼（イーノ・ドゥーエ）**:
  - 中央に「クモの目（spider_eye）」、上下左右（+字・十字配置）に「エンダーアイ（ender_eye）」を配置してクラフト。
- **装備スロット**: Curiosスロット「`magic_eye`」。一度に装備できる魔眼は1つのみ。

### 2.1 複写眼（アルファ・スティグマ / Alpha Stigma）
- **原作設定**: あらゆる魔法の構成式を瞬時に読み取り、模倣・再現できる魔眼。
- **Mod内効果**:
  1. **魔法解析・即時習得**: 通常は魔導書の研究等で覚える魔法を、敵や他者が放った魔法を見るだけで瞬時に習得可能。
  2. **魔法威力強化**: 魔法攻撃のダメージ・効果時間が2倍に上昇。
  3. **仕様**: 操作不能や強制自傷などの暴走システムは排し、純粋な強力魔眼バフとして扱いやすく設計。

### 2.2 殲滅眼（イーノ・ドゥーエ / Iino Doue）
- **原作設定**: 幼少期から肉を喰らい、魔法そのものを喰らって成長する魔眼。大気中の魔力や術者が放った魔法をすべて吸収・消滅させる。
- **Mod内効果**:
  1. **魔法使用不可＆魔法完全吸収**:
     - 殲滅眼着用中は術者自身も一切の魔法が使用不可。
     - 敵が放ったあらゆる魔法弾・魔法属性ダメージを100%吸収・無効化し、被ダメージ値を内部蓄積プールする。
  2. **着用中の永続パッシブ**:
     - 常時、移動速度+20%、跳躍力上昇、落下ダメージ半減、被物理ダメージ15%軽減（耐性I）が付与される。
  3. **アクティブ能力解放（「力を喰らい……それを放つ」）**:
     - 通常の魔法詠唱キーを押すことで発動。
     - 術者が「力を喰らい……それを放つ」と詠唱し、蓄積された魔法ダメージプールを**「全消費」**して一時覚醒モードに突入。
     - **持続時間スケーリング**:
       - 蓄積ダメージ量に正比例して覚醒の持続時間が延長（**蓄積10ダメージごとに +5秒**、最大60秒間）。
     - **覚醒中の強化内容**:
       - 金ハート（吸収 / Absorption II〜IV：蓄積量比例）
       - 攻撃力激増（攻撃力上昇 / Strength II）
       - 超高速機動（移動速度上昇 / Speed II）
       - ノックバック完全無効（Knockback Resistance 100%）
     - 反動デバフや固定クールダウンはなく、再び敵の魔法を吸収してダメージをプールすれば何度でも発動可能。
  4. **弱点・地中物理現象の透過**:
     - 地中から物理的に突き出る土砂や岩石（例: ローランド魔法「倒地」）、近接物理攻撃、矢などの実体投擲物は喰らうことができず、通常通りダメージを受ける。
     - ボス「運命の破壊者」の無詠唱魔法乱射に対する最大の対抗策となるが、「倒地」の回避が必須となる。

## 3. 開発・デバッグプレイ用コマンド体系（/legendmagic & /lm）
Modのテスト・検証、ダンジョン探索、およびマルチプレイでのデバッグを円滑化するための統合コマンド体系。
コマンドはOP権限（レベル2以上）のプレイヤーのみ実行可能。短縮エイリアス `/lm` が常時利用可能。

| サブコマンド | 構文 | 説明 |
| :--- | :--- | :--- |
| **全魔法習得** | `/lm learn all` | 上級魔法「稲死光」を含む全登録魔法（11種）を一括習得し、刻印スロットが空なら自動セット。 |
| **魔法リセット** | `/lm reset spells` | プレイヤーの習得魔法リスト・刻印スロット・選択インデックスを完全初期化。 |
| **マナ全快・設定** | `/lm mana [amount]` | マナを最大値まで即座に全快。数値を指定した場合はその値に設定。 |
| **スポーンエッグ一括** | `/lm eggs` | 全Mob・ボスのスポーンエッグ（全8種）を各64個プレイヤーのインベントリに付与。 |
| **検証キット一括** | `/lm kit test` | 魔導書、両魔眼、忘却欠片、台座、遺物の欠片、キーアイテム等の一式を付与。 |
| **構造物・次元TP** | `/lm tp <destination>` | 各国構造物（ローランド・エスタブール・ルーナ・ガスターク）またはディメンション（lab・menoris・overworld）へ安全地表足場を保証して直行テレポート。 |
