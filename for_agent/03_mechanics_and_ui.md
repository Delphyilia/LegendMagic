# 操作・システム・魔眼（Eye System） 仕様書

## 1. 魔法発動とインターフェース
### 1.1 ラジアルメニュー（Radial Menu）
- 専用キー（例: `R`キー または `V`キー）長押しで画面中央に円環（ラジアル）メニューが表示。
- 習得済み・装備中の魔法が体系別（ローランド・ルーナ・エスタブール）にアイコン表示され、マウスの向きで直感的に選択。
- キーを離すと選択された魔法がアクティブにセット。

### 1.2 詠唱（Casting）と魔法陣展開
- **通常魔法**:
  - 発動キー（または右クリック）で詠唱開始。
  - 術者の手元・足元に幾何学的な光の魔法陣が回転・展開。
  - HUDに詠唱ゲージおよび呪文名・詠唱文が表示される。
  - 詠唱中に被弾・ノックバック・移動制限違反等で詠唱が中断（キャンセル）されるリスク。
  - 詠唱完了の瞬間に魔法が発動。
- **上位魔法（ローランド専用・要解禁）**:
  - 詠唱時間：0 tick（完全無詠唱）。
  - 魔法陣展開なし。
  - 即時発動。

### 1.3 マナシステム（Mana System）
- プレイヤー画面（HUD右下または左下等）に専用マナバーを表示。
- 各魔法に行使マナコストを設定。
- 自然回復速度、最大マナ量は装備（装飾品・ローブ等）や成長によって拡張可能。
- マナポーション等による即時回復に対応。

## 2. 魔眼システム（The Eyes）
魔眼は通常の魔法とは異なり、プレイヤーの肉体・魂に宿る異能（または専用スロット/Curios装備）として機能する。

### 2.1 複写眼（アルファ・スティグマ / Alpha Stigma）
- **原作設定**: あらゆる魔法の構成式を瞬時に読み取り、模倣・再現できる魔眼。しかし保有者は精神を蝕まれ、いずれ暴走して化け物となる。
- **Mod内効果**:
  1. **魔法解析・即時習得**: 通常は魔導書の研究等で覚える魔法を、敵や他者が放った魔法を見るだけで瞬時に習得可能。
  2. **魔法威力強化**: 魔法攻撃のダメージ・効果時間が大幅に上昇（例: ダメージ2倍）。
  3. **暴走（Berserk）リスク**:
     - 魔法の連続行使、瀕死（HPが一定値以下）、または暴走ゲージの蓄積により強制的に【暴走状態】へ突入。
     - 両目に紅い五芒星（魔法陣）が浮かび上がり、操作不能（または敵味方の識別不能）となり、周囲の空間・敵・ブロックを無差別に消滅・分子崩壊させる超破壊光を撒き散らす。
     - 鎮静化には周囲の殲滅完了、または「だんご」等の精神安定アイテムの摂取が必要。

### 2.2 殲滅眼（イーノ・ドゥーエ / Iino Doue）
- **原作設定**: 幼少期から肉を喰らい、魔法そのものを喰らって成長する魔眼。大気中の魔力や術者が放った魔法をすべて吸収・消滅させる。
- **Mod内効果**:
  1. **自身の魔法使用不可**: 殲滅眼発動中は、魔力を喰らい尽くす性質上、術者自身も一切の魔法が使用できなくなる。
  2. **魔法完全吸収＆自己強化**:
     - 敵が放ったあらゆる魔法弾・魔法属性ダメージを100%吸収・無効化。
     - 吸収した魔力量に応じて、自身の攻撃力・移動速度・防御力・HP再生等の身体能力が爆発的に強化される。
  3. **弱点・物理現象の透過**:
     - 地中から物理的に突き出る土砂や岩石（例: ローランド魔法「倒地」）、近接物理攻撃、矢などの実体投擲物は喰らうことができず、通常通りダメージを受ける。
     - ボス「父」の無詠唱魔法乱射に対する最大の対抗策となるが、「倒地」の回避が必須となる。
